# Firebase Setup

1. Create Firebase project.
2. Register Android app package: `com.blastscreen`.
3. Download real `google-services.json` and replace placeholder file.
4. Enable Analytics, Crashlytics, Performance, Remote Config.
5. Publish Remote Config keys:
   - `admin_ui_enabled`
   - `ml_blur_enabled`
   - `layout_experiment`
   - `daily_minutes_limit`
